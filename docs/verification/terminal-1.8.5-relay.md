# Terminal 1.8.5 中继输入验收

隔离 Aide 用标准 ZIP 从 Terminal 1.8.4 升级到 1.8.5。两版在同一个浏览器测试夹具使用实际 xterm 可见行、OpenSSH 和 Python TLS 1.3 中继进行对照。夹具注入 80 ms 中继往返时延，远程 Aide 场景再注入 60 ms 浏览器至 Aide 的时延。

| 观察项 | 1.8.4 p50 / p95 | 1.8.5 p50 / p95 |
| --- | ---: | ---: |
| 本地 Aide，连续键入 | 180.0 / 217.9 ms | 144.6 / 173.7 ms |
| 远程 Aide，连续键入 | 385.4 / 468.1 ms | 271.8 / 337.2 ms |
| 远程 Aide，间隔单键 | 233.5 / 313.8 ms | 252.9 / 271.2 ms |

本地 Aide 输入调用的中位数从 50.0 ms 降至 21.3 ms。远程间隔单键在这次采样中中位数增加 19.4 ms，p95 缩短 42.6 ms。实际链路、远端应用和终端渲染的变化都会影响回显时延。

以上版本使用相同的中继部署脚本。针对性测试覆盖后台轮询让出、单请求约束、真实回显、回执不明时不重发，以及跨输入分段的 Unicode 粘贴。独立 Chromium、OpenSSH 和 TLS 夹具也通过了会话结束后的重连和正常输入验收。

`packages/v1.8.5/aide-pkg-terminal-v1.8.5.zip` 为 1,308,256 bytes，SHA-256 `b41804cca3249825ddb092556a4100b980b619f02c83be9e071b39995c81da43`。

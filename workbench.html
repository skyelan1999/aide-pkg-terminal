新建调试会话

独立连接，后台保留。输入会直接发送到所选设备。

先保存会话，下载包含目标参数和密钥的 Python 脚本，在设备侧运行后再连接。串口路径填写设备侧路径。部署脚本包含密钥，请妥善保管。

通信从 Aide 运行环境发起，本地监听仅绑定 127.0.0.1。TCP 监听接入后会新增客户端会话。

串口位于 Aide 运行环境中；容器需预先映射设备并具备访问权限。

首次连接请在终端核对设备指纹并确认。选择密码或私钥方式后，在终端提示中输入密码或私钥口令，不保存到连接记录。设备 SSH 从 Aide 运行环境发起。

本地回显可能把密码显示并写入输出日志，认证时请保持关闭。TLS 中继加密 Aide 到中继这一段；中继到 Telnet 目标仍使用 Telnet 原协议。

需要已有且可访问的 X Server、Aide 运行环境内的 xauth 和有效 Xauthority；远端 SSH 服务也需启用 X11Forwarding 并安装 xauth。支持独立 SSH 设备连接及其中继模式；工作区复用终端不支持，请新建独立 SSH 连接。不会自动安装 X Server 或修改系统权限。

设备输出可能包含敏感信息。日志不单独记录键盘输入；终端回显仍会保存。每个会话最多保留 4 × 2 MiB。

原始终端输出，保留 ANSI 控制序列。文件按轮转顺序排列。

复制会话

新会话拥有独立连接、输出和日志。中继副本复用同一个已部署中继及原目标，无需重新部署或填写密钥。不会复制密码或终端历史。

串口和固定端口监听属于独占资源。请先释放原资源，再手动连接副本。
